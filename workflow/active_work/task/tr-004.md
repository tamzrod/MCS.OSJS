# OTR-004 — Gateway Implementation Verification

**Status**: READY FOR EXECUTION  
**Stage**: ACTIVE TASK  
**Owner**: OpenCode  

---

## Objective

Verify socket connection patterns, API integration, and contract testing for the ModbusToolkit gateway layer. This task validates that:

1. Socket endpoints expose correct operations
2. API contracts align with backend implementations
3. Connection patterns match documentation
4. Contract validation passes end-to-end

---

## Verification Targets

### 1. Socket Endpoint Validation

Verify each socket exposes expected operations per contract:

| Socket | Expected Operations | Purpose |
|--------|---------------------|---------|
| `modbus-simulator.sock` | `load`, `apply`, `status` | Simulation operations |
| `modbus-replicator.sock` | `load`, `apply`, `read`, `write`, `suggest` | Replication operations |

### 2. Contract Testing Matrix

Test contract parity between UI/API consumers and backend socket implementations:

- Load simulation request/response
- Apply simulation payload execution
- Status polling for availability checks
- Read incoming replication data
- Write acknowledgment for incoming data
- Suggest planning operation (if applicable)

### 3. Integration Verification

Validate connections flow through expected paths:

- Electron API → Server Router → Unix Socket
- JSON request/response headers/length prefixes
- Schema validation at gateway layer

5. **Update handoff.md** with verification results
