# Active Work

This directory contains only human-promoted work authorized for JR execution.

An Active Task may contain the execution information required to continue and verify that task.

## ICC-First Context Rule

Active Work must be consumed through Operation CWAL.

CWAL reads `ICC/INDEX.md` first and uses synchronized relevant ICC context. If that context is stale or missing, BLACK SHEEP WALL refreshes only the affected context before execution continues.

If HEAD is unchanged from the ICC baseline, only uncommitted files whose current state differs from the last audited overlay should be inspected. Unchanged repository knowledge must not be recomputed.

BLACK SHEEP WALL cannot select Active Work, inspect Planning to choose work, grant authority, or widen the active task.

Do not place future backlog, brainstorm material, or speculative work here.

If this directory contains no active task, JR stops and waits for human promotion.
