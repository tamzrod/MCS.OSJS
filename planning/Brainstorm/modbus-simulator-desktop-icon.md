# Brainstorm: Modbus Simulator Desktop Icon

Status: brainstorm material only. Non-authoritative. No implementation authorized until human promotion.

Date: 2026-09-11. Owner: human.

## Intent

Add a Modbus Simulator shortcut/icon to the OS.js desktop so the existing Simulator can be launched directly from the desktop.

## Scope

- Show a Modbus Simulator icon/shortcut on the OS.js desktop.
- Clicking the icon launches the existing Modbus Simulator application.
- Reuse the existing Simulator application identity/icon/metadata where practical.
- Keep the shortcut consistent with the existing OS.js desktop behavior and visual style.

## Non-scope

- No Simulator runtime changes.
- No Simulator backend changes.
- No Simulator window/UI redesign.
- No Replicator work.
- No new application behavior beyond desktop launch access.

## Desired Outcome

After OS.js starts, the user can see a Modbus Simulator icon on the desktop and launch the existing Modbus Simulator by opening that icon.
