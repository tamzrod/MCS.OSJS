## Proposed shared Go authority and safety contract — NOT YET APPROVED

1. Reuse existing Go Simulator local Unix v1 4-byte BE framed JSON service for two NEW operations `mma-load`/`mma-apply` on Memory-only namespace, no HTTP, browser YAML writes, Windows preload/IPC, Windows service/binary dependency or third-party legacy app import. `mma-load` requires authenticated Toolkit session; `mma-apply` additionally requires proven server-side manage-MMA capability. `_osjs_client` proves authentication only; if OS.js capability API is unresolved, deny all mutating requests. Browser never supplies ownership identity. Whitelist root `rbe`, `access_events`, `debug`; no per-device field via shared operation.
2. `mma-load` returns `{settings:{rbe?,access_events?,debug?},revision:<sha256 of exact effective config bytes>}`; `mma-apply` requires `{settings:<whitelisted patch>,expected_revision:<loaded revision>}`. Missing/invalid revision, unknown key, unsafe listener or stale CAS => typed error and zero changes. Null means explicit removal, absent means unchanged. Correlated v1 request_id and existing 1 MiB cap, typed INVALID_REQUEST/FORBIDDEN/REVISION_CONFLICT/VALIDATION_FAILED/RUNTIME_UNAVAILABLE/APPLY_RECOVERY_REQUIRED. Return a truthful success only after restart ack/readiness; no-op/read must not restart.
3. One cross-process Linux host-volume lock must be held around FULL read/compare/compose/validate/commit/restart-ack for EVERY writer: Simulator, Replicator and shared Go manager; lock management reads too. Implement bounded wait, crash release, permissions and no nested deadlock before enabling `mma-apply`. An intra-process mutex or compositor `Commit` alone is insufficient. Under the same lock preserve owners unchanged for root-only edit, foreign memories, listener ID/listen/metadata, root extras, original bytes/revision. Validate COMPLETE candidate with Go MMA2 validator and RBE checks BEFORE write. Partial write failure restores original bytes. After committed config but failed ack/readiness: do NOT blindly roll back potentially live state; return APPLY_RECOVERY_REQUIRED and retain prior/current fingerprints and operator reconciliation evidence; compensating restart needs a separately proven procedure. No false success.
4. Canonical Simulator load must project omitted policy/sealing/RBE from effective config by `(port,unit_id)` WITHOUT writing new YAML, respecting explicit false/empty/null and preserving extras; corrupt effective source fails explicitly. Device save through existing producer composer; shared save never calls device `apply`. Duplicate remaps RBE IDs globally without modifying foreign-owned devices. Modal holds separate persisted/draft snapshots: Close retains unsaved, Discard resets only shared, Save sends one revision-checked apply, conflict demands explicit reload/review.
5. RBE TCP draft `MMA2/docs/RBE_V1_DRAFT.md` is NOT LOCKED, unauthenticated/no replay/latency proof. Keep global RBE and access-event network listeners off/unpublished by default; form may display them disabled with reason until independent network/auth/bind approval. No implicit port, no customer/production enablement.

## Proposed Replicator COMMS contract — no fabricated green

Use existing validated v1 status; match exact selected persisted name plus enabled/running and ordered block index/function/start/count against canonical Pull Blocks; reject missing/legacy schema, wrong identity, old selections, stopped/disabled runtimes or transport error to UNKNOWN. Verify block `last_poll` and layer `observed_at` valid and no older than `max(10 seconds, 3 * scan_rate_ms)` and not >5 seconds future; apply response-reception freshness separately. OK requires current-cycle matching per-layer Go evidence, not only aggregate source OK. Aggregate current blocks ERROR > WARNING > UNKNOWN > OK; Network successful TCP connect only (not ping), failed connect leaves Network UNKNOWN. Respect real Modbus exception WARNING, TCP failure, MMA2 Raw Ingest ACK only; skipped write cannot be OK. Tooltips include endpoint/error/time; activity pulse only new valid timestamp and reduced-motion aware. On invalid/stale/missing reply, clear stale green promptly including on window teardown.
